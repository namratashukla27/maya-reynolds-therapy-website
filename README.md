# Maya Reynolds Therapy Website

A responsive and professionally designed therapy website created for Dr. Maya Reynolds, PsyD, a Licensed Clinical Psychologist based in Santa Monica, California.

The website is designed to provide a calm, welcoming, and trustworthy online experience while clearly presenting the therapist's services, therapeutic approach, office environment, and consultation pathway.

##

## Project Overview

This project focuses on building a clean and responsive front-end website for a mental health professional.

The design was developed around a calm and professional visual style with clear content hierarchy, balanced spacing, readable typography, responsive layouts, and straightforward navigation.

The website presents information about Dr. Maya Reynolds and her work with adults experiencing anxiety, trauma, burnout, and perfectionism.

## Features

* Responsive navigation
* Responsive design for desktop, tablet, and mobile devices
* Hero section with primary call-to-action
* Therapist introduction and profile section
* Anxiety therapy section

## Services Presented

### Anxiety Therapy

Information for adults experiencing anxiety, worry, panic, overthinking, and persistent tension.

### Trauma Therapy

Information for adults affected by single-incident trauma or longer-standing experiences related to childhood, relationships, or chronic stress.

### Burnout Therapy

Information for adults dealing with professional burnout, perfectionism, high internal pressure, and prolonged stress.

## Therapist Profile

Dr. Maya Reynolds, PsyD is presented as a Licensed Clinical Psychologist based in Santa Monica, California.

Her approach is described as warm, collaborative, and grounded, incorporating evidence-based methods including:

* Cognitive Behavioral Therapy (CBT)
* EMDR
* Mindfulness-based practices
* Body-oriented techniques

The website also communicates that in-person therapy is offered from the Santa Monica office and secure telehealth sessions are available for clients located in California.

## Our Office

The website includes a dedicated Our Office section using the provided office photographs.

The section presents the therapy environment as a quiet, private, comfortable, and grounding space with natural light and an uncluttered atmosphere.

## Design Approach

The visual design was created to communicate a calm, warm, professional, and approachable experience.

The design uses:

* Natural and warm tones
* Clear typography hierarchy
* Generous whitespace
* Consistent spacing
* Structured content sections
* Simple and purposeful interactions
* Responsive layouts
* Minimal visual distractions

The interface avoids excessive animations and unnecessary visual elements in order to keep the focus on the content and user experience.

## Responsive Design

The website has been designed to adapt to different screen sizes, including:

* Desktop
* Laptop
* Tablet
* Mobile devices

Responsive considerations include navigation, typography, content width, image sizing, section spacing, buttons, and multi-column layouts.

## Getting Started

### Prerequisites

Make sure Node.js and npm are installed on your system.

### Clone the Repository

```bash
git clone https://github.com/namratashukla27/maya-reynolds-therapy-website.git
```

### Navigate to the Project

```bash
cd maya-reynolds-therapy-website
```

### Install Dependencies

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

The development server will provide a local URL that can be opened in a browser.

## Production Build

To create a production build:

```bash
npm run build
```

The optimized files are generated in the `dist` directory.
